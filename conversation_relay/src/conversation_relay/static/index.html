Configuration

Switch backend mode

Edit the app's .env file and restart the app to change modes. 

HF_REALTIME_CONNECTION_MODE=deployed
HF_REALTIME_CONNECTION_MODE=local
HF_REALTIME_WS_URL=ws://127.0.0.1:8765/v1/realtime

Optional: set HF_TOKEN in .env (a free token from huggingface.co/settings/tokens) for more reliable access to the hosted backend.
